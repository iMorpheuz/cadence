# CADENCE

A unified dark-studio tracker combining daily productivity habits, progressive workout ladders with animated kinematic form demos, calorie/fuel logging, physique/BMI goal tracking, and unified XP & rank progression.

## Modules

- **Today**: Daily quest/habit tracker with attribute tags, streaks, XP rewards, and a 3-pillar pulse strip.
- **Train**: Progressive Daily Ladder (`Build Up` or `At The Ink` modes), superset pairing, guided set runner with rest countdowns, animated 3-angle SVG `FormLoop` demos, Physique/BMI goal tracking, and weekly/monthly burn charts.
- **Fuel**: Daily calorie tracking, searchable food library, 1-tap quick-log chips, and meal slot organization.
- **History**: Interactive 7-day habit + workout + fuel matrix and a combined monthly intensity heatmap.
